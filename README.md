# FDE Career Research

**Live site: https://konradsikorski5.github.io/fde-career-research/**

**Career comparison (Legora vs EliseAI): https://konradsikorski5.github.io/fde-career-research/compare**

A research collection on Forward Deployed Engineer (FDE) roles: internships and full-time positions taken from real employer postings. Every posting was checked on its employer's own job board on 2026-11-12.

- [Internships](https://konradsikorski5.github.io/fde-career-research/internships): 6 open postings
- [Full-time](https://konradsikorski5.github.io/fde-career-research/full-time): 3 new-grad and 10 experienced postings
- [What the role does](https://konradsikorski5.github.io/fde-career-research/role)
- [Skills employers ask for](https://konradsikorski5.github.io/fde-career-research/skills)
- [Sources & check dates](https://konradsikorski5.github.io/fde-career-research/sources), including expired listings

Built with [VitePress](https://vitepress.dev/) and deployed to GitHub Pages by GitHub Actions on every push to `main`.

## Run locally

```bash
npm ci
npm run docs:dev
```
