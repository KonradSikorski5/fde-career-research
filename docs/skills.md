## What to build to show these skills

These are **my suggestions**, not employer statements. Each project targets skills from the table above.

1. <span id="p1"></span>**A small LLM app for a real person's workflow.** Interview a user, scope the app, build it in Python or TypeScript, deploy it, and write down what changed for them. *Covers: customers, Python/TS, LLMs, deployment.* (I3 counts personal AI projects. F6 says "side projects and prototypes count.")
   - **How to check it:** the person I built it for does their task with the app while I watch, without my help, and I write down whether it worked and how long it took.
2. <span id="p2"></span>**An evaluation harness for that app.** Make a test set, measure accuracy, and show a before/after improvement. *Covers: evals (I5, F5, F7, F9).*
   - **How to check it:** running one command scores the app on a saved test set (for example, 20 questions) and prints the accuracy, and the score goes up after one change I make.
3. <span id="p3"></span>**A self-hosted deployment with a write-up of a failure.** Run the app on Linux or Kubernetes, break something, and write a root-cause analysis (RCA). *Covers: infra, debugging (I4, I6).*
   - **How to check it:** a classmate follows my README to start the app on Linux, I break one thing on purpose, and my RCA lets them find the cause.
4. <span id="p4"></span>**A one-page case study per project:** problem, user, what you built, result, and what you'd change. This is evidence of the communication skill nearly every posting asks for.
   - **How to check it:** a classmate reads only the case study and can say who it was for, what I built, and what I'd change.
