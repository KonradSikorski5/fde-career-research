## Evidence vs. assumptions

**From the postings (evidence):**
- Both ask for clear communication with non-technical people. Legora: "explaining technical work to engineers and nontechnical stakeholders." EliseAI: "strong written and verbal communication skills."
- Both ask for finding why something broke. Legora: "debug issues … using logs, tests, and systematic investigation." EliseAI: "investigate issues' root cause … using SQL queries, logs."
- EliseAI asks for written bug tickets that show how to reproduce the issue and its impact.
- Legora's role builds the fix. EliseAI's role finds and documents the problem, then follows up with the client.

**My assumptions (not checked):**
- That a written, step-by-step case study is a fair stand-in for "work experience" in a student portfolio.
- That these two postings are typical. This is only 2 postings. The [19-posting collection](/sources) shows the same communication and debugging themes, but it is still a sample.

## Alternatives I considered

| Direction | Fits | Gives up |
|---|---|---|
| **Solutions / support engineer** (EliseAI) | Closer to what I can show now: investigating, documenting, communicating | Less building of new features |
| **Forward Deployed Engineer** (Legora) | Builds the fix too, which I enjoy more | Asks for more production experience than I can show yet |

I'm not choosing one yet. Both share the same first skill to prove.
